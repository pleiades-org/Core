# Core v2 — Windows x64 release, 22 September 2026 (second build)

Portable executable: `dist/Core-v2-windows-x64/core-v2.exe`. Extract the ZIP before running. Requires 64-bit Windows and the Microsoft Visual C++ v14 x64 runtime. Core does not require administrator access. Existing settings load unchanged. This is an unsigned alpha build.

## Included changes

**Smart conversions and calculations.** Core answers everyday conversion questions typed directly into search. The [full syntax reference](SMART_CONVERSIONS.md) lists every form.

| Area | Examples |
| --- | --- |
| Units, 15 kinds | `4.7GB to MiB`, `100 mbps to MB/s`, `30 mpg to l/100km`, `1 acre to m2`, `1 kWh to J`, `9 pt to cup` |
| Currency | `100 usd to eur`, `£50 in dollars`, `€1.5k to yen`, bare `100 usd` converts to your regional currency |
| Downloads and pace | `10 GB at 100 Mbps`, `10 GB in 10 min`, `100 Mbps for 2 hours`, `5 km in 25 min` |
| Percentages | `20% off 80`, `20 is what % of 80`, `% change from 50 to 75`, `15 is 20% of what` |
| Tips and bills | `tip 15% on 80 split 4`, `split 120 3 ways` |
| Number bases | `255 to hex`, `0xff`, `2024 to roman`, `MMXXIV to number` |
| Colours | `#ff8800`, `rgb(51, 102, 153) to hex`, `hsl 210 50 40 to rgb` |
| Unix time | `unix 1700000000`, `unix now` |
| Screens | `1920x1080`, `16:9 1440 wide`, `ppi 2560x1440 27in` |
| Finance | `mortgage 250k at 4.5% for 25 years`, `compound 1000 at 5% for 10 years monthly` |
| Health | `bmi 70kg 175cm`, `bmi 11st 5'9"` |

Multi-part answers (tip, colour, bases, loans) appear as separate rows; Enter copies the selected row. The result heading now reads **CONVERSION**. Unit results are rounded to 12 significant figures, so `10 pounds to kg` shows `4.5359237 kg` instead of `4.535923700000001 kg`. Time-zone queries keep priority when complete (`9 pt to et`), while `9 pt to cup` converts pints.

**Website quicklink icons.** Website quicklinks show the site's `/favicon.ico`; file and folder quicklinks show their Windows icons. See the README for caching and privacy details.

## Network use

Searching never uses the network. Two background features may, only while Core is shown and never in `--dry-run` (unless `--test-network` is given):

- **Website icons:** Core requests `/favicon.ico` from a site you saved as a quicklink, and caches it for 30 days.
- **Exchange rates:** Core downloads `eurofxref-daily.xml` from the European Central Bank when the cached copy is more than 12 hours old, and waits 15 minutes after a failure. Cached rates load first, so conversion works offline with the last downloaded rates. The rate date is shown in every currency answer.

Requests send no cookies or credentials, are size-limited, and time out after a few seconds. `--exchange-rates-file <path>` pins a fixed ECB file for testing or offline use.

## Internal changes

Conversions live in a new engine module, `crates/engine/src/conversions/`, with one file per family. The previous unit converter moved there with its tests unchanged. The HTTP client shared by icons and rates is `crates/launcher/src/windows/http.rs`. The Windows calendar clock gained Unix-time methods, and search requests carry an immutable exchange-rate snapshot.

## Validation

Rust: 72 engine tests and 36 launcher tests pass, including three ignored tests run explicitly: registry, live favicon download and live ECB download. Engine tests cover every conversion family, routing order, currency with and without rates, and floating-point formatting (a `readable(0)` overflow was found and fixed). `cargo clippy --workspace --all-targets -D warnings` is clean.

All eight native release scripts pass against the packaged executable (the controls hover check passed on a rerun after one failure: it moves the real mouse pointer on the shared desktop), with PowerShell 7 and no injected keyboard input, as in previous releases. The extensions harness now also checks currency (using the fixture `scripts/fixtures/ecb-rates.xml`), download time, number bases, percentages, colours, pints versus Pacific time and unit rounding. A manual run against the live ECB file of 22 September 2026 checked 42 queries in the running app.

## Remaining limitations

- Currency covers only ECB reference currencies; no cryptocurrencies or intraday rates.
- Website icons declared only in page HTML are not found, and dark favicons can be hard to see on black.
- Taskbar reveal and the live tray glyph were not checked visually on this PC's auto-hidden taskbar.
- Secure-desktop, physical mixed-DPI switching, IME-candidate and screen-reader acceptance remain manual.
- There is no installer or signing.
