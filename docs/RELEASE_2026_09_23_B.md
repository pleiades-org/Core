# Core v2 — Windows x64 release, 23 September 2026 (second build)

Portable executable: `dist/Core-v2-windows-x64/core-v2.exe`. Extract the ZIP before running. It requires 64-bit Windows and the Microsoft Visual C++ v14 x64 runtime, and does not need administrator access. Settings, command history and recent apps load unchanged. This is an unsigned alpha build.

This build fixes two display problems in the [first 23 September build](RELEASE_2026_09_23.md).

## Fixes

**Recent-app icons now appear.** Icons load in the background after the grid is drawn, and each finished icon asked the hidden result list to repaint instead of the grid. Tiles kept their placeholder until something else repainted them, such as a hover. The grid now repaints as each icon arrives.

**The power button is drawn on first appearance.** Each time Core is shown it now repaints every control. Moved controls are also redrawn instead of reusing the pixels they had in their old position (`SWP_NOCOPYBITS`). The button was missing only on first appearance: Core is laid out while hidden, then moved to its display and resized when first shown.

## Validation

- **Rust:** 82 engine tests and 74 launcher tests pass. `cargo clippy --workspace --all-targets -D warnings` is clean.
- **Release scripts:** all eight background scripts pass against the packaged executable.
- **Icon fix:** before the fix, a capture of the first appearance, using a copy of the person's own appearance settings, showed placeholders on every tile but one. After the fix, every tile had its icon.
- **Power button:** the missing button could not be reproduced in the test environment. The fix follows the reported behaviour (first appearance only) and needs confirming on the affected PC.
