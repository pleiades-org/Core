# Core v2 — Windows x64 release, 23 September 2026 (fifth build)

Portable executable: `dist/Core-v2-windows-x64/core-v2.exe`. Extract the ZIP before running. Existing settings, quicklinks, command history and recent apps are preserved.

## Included changes

- `time` shows the current local time and `date` shows today's date in the existing large calculator answer display. Both are case-insensitive and work with `@calc`. Enter copies `YYYY-MM-DD HH:MM` for time and `YYYY-MM-DD` for date.
- The footer shows one hint for the selected action, such as **Enter to copy**, **Enter to open**, or **Enter to confirm**. It follows keyboard and mouse selection.
- A centred local clock displays `HH:MM` and updates at the next minute. It stops while Core is hidden or Settings is open and refreshes when search is shown again.
- Shell breadcrumbs are removed from the footer. The working directory remains in the terminal prompt. Errors, exit codes and command completion status remain available.

The previous terminal, conversion, application search and quicklink features remain included.

## Validation

- 83 engine tests and 100 launcher tests pass; three opt-in tests for registry writes and live network downloads remain ignored. Formatting and Clippy checks pass.
- Packaging requires passing records for all eight background release scripts against this exact executable. Records are in `docs/measurements/release-*.json`.
- The time-conversion integration check now expects the concise copy hint while retaining its result, date and daylight-saving assertions.
- Background captures confirm the calculator answer, action hint and centred clock render together.
- The first settings check encountered an invalid cached monitor handle and a position mismatch. An unchanged isolated rerun passed. The first integration check expected the old footer text; its assertion was updated to the new action hint.
- Interactive click-away dismissal and pointer hover checks were not rerun; the package record marks interactive checks as skipped.

## Remaining limitations

The unsigned portable build requires 64-bit Windows 10 version 1809 or later and the Microsoft Visual C++ v14 x64 runtime. Physical mixed-DPI monitor switching, screen-reader acceptance and the terminal limitations described in the fourth-build notes remain unchanged.

An existing settings issue can leave the window at its previous position if the external foreground window used as the monitor reference has closed. The failed background run logged `Invalid monitor handle`; reopening Core refreshes the monitor reference. This packaging update does not change monitor selection.

See [the fourth-build notes](RELEASE_2026_09_23_D.md) in the source repository for the terminal implementation and its remaining limitations.
