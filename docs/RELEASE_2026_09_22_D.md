# Core v2 — Windows x64 release, 22 September 2026 (fourth build)

Portable executable: `dist/Core-v2-windows-x64/core-v2.exe`. Extract the ZIP before running. It requires 64-bit Windows and the Microsoft Visual C++ v14 x64 runtime, and does not need administrator access. Existing settings and command history load unchanged. This is an unsigned alpha build.

This build fixes how `/` commands looked in the [third build](RELEASE_2026_09_22_C.md).

## Included changes

**`/` works like a terminal.** While the query is a command, the result rows are hidden, and output appears inline in their place, on the window's own background. The output grows with its text up to 360 px, then scrolls; the scroll bar appears only then. The keys replace the rows:

| Keys | What happens |
| --- | --- |
| Enter | Runs hidden, with the output in Core |
| Ctrl+Enter | Opens a terminal |
| Ctrl+Shift+Enter | Opens a terminal as administrator |
| ↑ and ↓ | Step through recent commands, newest first. Text typed before the first ↑ filters them, so `/git` then ↑ recalls only `git` commands. |

**Clean PowerShell output.**
- Errors and progress no longer appear as `#< CLIXML` and `<Objs …>` markup. Hidden runs now use `-Command` instead of `-EncodedCommand`, which writes those streams as XML once output is redirected. The command is passed through an environment variable, so quoting is unaffected.
- Syntax errors point at what was typed.
- A handled error (`try … catch`) no longer reports exit code 1.
- Table rows are no longer double-spaced. PowerShell pads each row to 120 columns, and the padding wrapped onto a second line. Trailing spaces and trailing blank lines are now removed.

## Remaining limitations

- Terminal and administrator runs have no rows to click; they need Ctrl+Enter or Ctrl+Shift+Enter. The automated tests check them in dry run only, because the harness cannot hold modifier keys without taking the keyboard.
- Hidden runs have no input, so interactive programs (`ssh`, `python`, prompts) end immediately. Use Ctrl+Enter for these.
- PowerShell still wraps long error lines at 120 columns, and the output wraps lines wider than the window.
- Command history is plain text. Avoid typing secrets into commands.
- Secure-desktop, physical mixed-DPI switching, IME-candidate and screen-reader acceptance remain manual.
- There is no installer or signing.
